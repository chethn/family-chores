# Family chores

A small chores-and-rewards app for Dad, Mom, Akin, and Niko. The site is static: open `index.html` from any web server (modules and the API will not work from a `file://` URL).

GitHub Pages should serve the **main** branch from the **root** folder: <https://chethn.github.io/family-chores/>

The browser talks only to the Supabase RPCs described in `docs/API.md`. Each person picks their name and a 4-digit code. The code stays on that device.

Add it to the home screen from Safari or Chrome for a full-screen icon.
